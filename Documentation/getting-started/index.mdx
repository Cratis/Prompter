<YouWillLearn>

- choose a way to ask Prompter a question
- check a reply against its cited sources
- continue with a more specific question or ask a person for help
- use the 👍/👎 feedback buttons when they are available

</YouWillLearn>

Join the [Cratis Discord](https://discord.gg/kt4AMpV8WV) and use a server channel where Prompter is enabled.
Being able to read a channel does not by itself mean the bot can answer there. If you are not sure where
to ask, check with a community member. You do not need to run your own instance to follow this walkthrough.

<Steps>

1. **Ask by mentioning.** In a channel where Prompter is enabled, mention it with one question in the same
   message. Name the product and what you are trying to do:

   ```text
   @Prompter how do I append an event in Chronicle?
   ```

2. **Check the reply.** If the reply includes a `Sources:` line, open a linked page and check that it
   supports the claim or instruction you plan to use. A citation is a route to the evidence, not proof
   that the reply is correct. Prompter can also ask you to clarify the question or refuse when it cannot
   find grounding; neither tells you that the feature is unavailable.

3. **Say what helped or what is missing.** Use **👍 Helpful** or **👎 Not helpful** when the feedback
   buttons are present. If the reply missed the point, explain what differs from your situation in the
   channel or thread. Feedback helps identify problems, but it does not itself request or guarantee a
   human response.

</Steps>

## All the ways to summon it

<Tabs>
  <TabItem label="@mention">
    Put the question and mention in the same message in a channel where Prompter is enabled. The reply
    may appear on your message or in a new thread, depending on the channel configuration.

    ```text
    @Prompter what's the difference between a projection and a reducer?
    ```
  </TabItem>
  <TabItem label="/ask">
    Use the slash command for a standalone question in an enabled server channel. An admitted request
    is acknowledged while Prompter works on the reply; limits or a failure may prevent an answer.
  </TabItem>
  <TabItem label="Ask channel">
    If the server has a configured ask channel, post your question there without a mention. Do not
    assume that an ordinary channel treats every message as a question.
  </TabItem>
  <TabItem label="Help forum">
    Open a post in the configured help forum with your question and the context someone would need to
    help. Prompter can reply automatically there, but neither an immediate answer nor a human response
    is guaranteed. Operators can also enable delayed replies to unanswered posts in other forums.
  </TabItem>
</Tabs>

For a question already written in a person's text message, **Ask Prompter** requests a public answer on
that message or in an applicable answer thread. Only the acknowledgment is private to you. If that is the
visibility you want, select the message and choose **Ask Prompter** from its context menu in an enabled
server channel.

For a follow-up, reply to Prompter's message and say which part you want to understand next. Keep the
product and relevant details in the question rather than assuming the bot remembers everything. If a
person joins the discussion, keep the question in that conversation; you can mention Prompter or reply
to its message when you want the bot to answer again.

:::note[When it says "I don't know"]
A refusal means Prompter could not find enough grounding for this question, not that your task is
impossible. Try naming the product, the exact feature or the error you are seeing. If that still does not
help, ask the community in the same channel or thread and explain what remains unresolved. When an
**Ask a human** button is available, only the person who asked can use it to request help; it does not
guarantee that someone is available to respond.
:::

If the reply gives you a wait time, wait before trying again. If there is no reply, check that you used an
enabled channel and one of the asking methods above rather than repeatedly posting the same question.

<Recap>

Your next question may be about the task itself: what part of the reply applies to your situation, and
what detail is still missing? You can ask that follow-up without having completed every step above.
[Use Prompter on Discord](/prompter/guides/using-prompter/) has more detail on asking and continuing a conversation.

For the reason behind a refusal or the limits of a citation, read
[Grounded answers](/prompter/concepts/grounded-answers/). If the bot did not answer or behaved unexpectedly,
start with the [FAQ](/prompter/reference/faq/).

</Recap>
